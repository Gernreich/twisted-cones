Twisted Ellipse Sweep

← All projects · Twisted cones

Every position of the ellipse is kept, so the sweep shows as a lit solid. Two ellipses start together: the original from (10, 0, 0) to (0, 0, 190) (copper) and its mirror from (−10, 0, 0) to (0, 0, 190) (blue), both with y within ±10. Both follow the same rule. As each rises by h it turns counter-clockwise about the z axis (seen from above) by τ·h/1000 and shrinks about the shared end at (0, 0, 190), which stays on x = 0, y = 0.
