Each variation changes one thing about the twisted, offset cone. Every slice is level and touches the z axis (except the gap variations). Height runs 0 to 1166.43, with the same twist rule unless the twist is what varies. The Base slice switch swaps the circle and the 1 : 2 ellipse in every variation that does not change the slice itself. Click any thumbnail to open it in the large view.

Mix any combination of slice, twist, taper, copies, gap, wall and build. Every slice is level; it touches the z axis unless a gap is set. Height runs 0 to 1166.43 (¼ of that for the ¼-scale stack). Start from a thumbnail below or set the buttons yourself, then save combinations you like to the sheet.
